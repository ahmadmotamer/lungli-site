语言交换中如何纠正错误

Lungli 团队 · 发布于 2026年10月20日 · 阅读约 1 分钟

互相纠正是语言交换的核心，也是最容易做错的部分。纠正得太少，谁都学不到东西；纠正得太多或太生硬，对话就会中断。下面告诉您如何给出有帮助的纠正，以及如何接受纠正。

先约定好

一开始，问语伴一个简单的问题：“您希望我纠正到什么程度？” 有人希望每个错误都被指出；大多数人只希望纠正重要的。有人喜欢在对话中途被纠正；也有人更喜欢在最后。事先约定好，之后就不会有人觉得被冒犯。

纠正什么

您不必什么都改。重点关注：

  • 改变意思的错误——当您不确定语伴想表达什么，或者别人可能会误解时。
  • 反复出现的错误——同一个错误出现在好几条消息里，值得清楚地指出一次。
  • 正确但不自然的说法——"It is a good idea" 没错；但人们实际会说的是 "Good idea!"。

小的口误就放过吧，尤其是当语伴在尝试难的表达时。流利是在尝试中成长的。

如何纠正得好

  • 给出自然的说法。 "I went to London last year" 比一句“时态错了”更有教益。
  • 可以的话，附上简短的原因。 “'Last year' 是已经结束的时间，所以英语用一般过去时。”一行就够了。
  • 说明错误的类型。 语法、词汇、拼写、用词——这能帮助语伴看出规律。
  • 让对话继续下去。 先纠正，再回应对方说的内容。重要的是消息本身，而不只是它的语法。
  • 态度友善。 一个微笑、一句“差一点！”或“这个错误很常见”，效果大不一样。

生硬的纠正与友善的纠正

✕ "Wrong. It is went, not have went."

✓ "I went to London last year 🙂 — 'last year' is finished, so English uses the simple past. Did you like London?"

第二种说的是同一件事，却解释了原因，也让对话继续下去。

接受纠正

  • 说声谢谢。 这会鼓励语伴继续帮助您。
  • 不要和母语者争论什么说法更自然——但如果好奇，可以问问为什么。
  • 把纠正连同整句话记下来。 第二天复习一遍，才能真正记住。
  • 留意自己的规律。 如果同一类错误反复出现，那正是您该学习的地方。
