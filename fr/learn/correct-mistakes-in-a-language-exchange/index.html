Comment corriger les erreurs dans un échange linguistique

Par l'équipe Lungli · Publié le 20 octobre 2026 · 3 min de lecture

Se corriger mutuellement est au cœur de l'échange linguistique — et c'est aussi la partie la plus facile à rater. Trop peu de corrections, et personne n'apprend ; trop de corrections, ou des corrections trop sèches, et les conversations s'arrêtent. Voici comment donner des corrections utiles, et comment les recevoir.

Mettez-vous d'accord d'abord

Au début, posez une question simple à votre partenaire : « Dans quelle mesure souhaitez-vous que je vous corrige ? » Certaines personnes veulent qu'on relève chaque erreur ; la plupart préfèrent seulement les plus importantes. Certaines aiment être corrigées pendant la conversation ; d'autres préfèrent à la fin. S'accorder d'abord évite que quelqu'un se sente attaqué ensuite.

Que corriger

Inutile de tout rectifier. Concentrez-vous sur :

  • Les erreurs qui changent le sens — quand vous n'êtes pas sûr de ce que votre partenaire voulait dire, ou que quelqu'un d'autre pourrait mal comprendre.
  • Les erreurs qui reviennent — la même faute dans plusieurs messages mérite d'être signalée une fois, clairement.
  • Ce qui est correct mais peu naturel — "It is a good idea" est juste ; "Good idea!" est ce que les gens disent vraiment.

Laissez passer les petites erreurs, surtout quand votre partenaire tente quelque chose de difficile. L'aisance progresse en essayant.

Comment bien corriger

  • Montrez la version naturelle. "I went to London last year" apprend davantage que « mauvais temps ».
  • Ajoutez une courte raison quand vous le pouvez. « "Last year" est révolu, donc l'anglais emploie le prétérit. » Une ligne suffit.
  • Nommez le type d'erreur. Grammaire, vocabulaire, orthographe, choix du mot — cela aide votre partenaire à repérer des régularités.
  • Faites vivre la conversation. Corrigez, puis répondez à ce qu'il a dit. Le message comptait, pas seulement sa grammaire.
  • Soyez bienveillant. Un sourire, un « presque ! » ou un « c'est une erreur fréquente » font toute la différence.

Une correction sèche et une correction bienveillante

✕ "Wrong. It is went, not have went."

✓ "I went to London last year 🙂 — 'last year' is finished, so English uses the simple past. Did you like London?"

La seconde dit la même chose, l'explique et fait vivre la conversation.

Recevoir des corrections

  • Dites merci. Cela encourage votre partenaire à continuer de vous aider.
  • Ne contestez pas ce qui sonne naturel aux oreilles d'un natif — mais demandez pourquoi, si vous êtes curieux.
  • Notez la correction, avec la phrase entière. La revoir le lendemain, c'est ce qui la fait tenir.
  • Repérez vos schémas. Si le même type d'erreur revient sans cesse, c'est cela qu'il faut étudier.

Les corrections sur Lungli

Lungli intègre tout cela dans la discussion. Vous pouvez corriger n'importe quel message de votre partenaire : écrivez-le comme vous le diriez, choisissez le type d'erreur et ajoutez, si vous le souhaitez, une note expliquant pourquoi. Votre partenaire voit la correction juste sous son message et peut l'enregistrer dans sa Mémoire pour la revoir plus tard.
